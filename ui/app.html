How to get the file
  • Easiest: build the frame around the 3D for CAD export, then save the frame with the same axes and origin. It lines up with no moving.
  • SolidWorks: File → Save As → STL. Under Options pick the units and a coarse resolution to keep the file small.
  • Onshape: right-click the part or Part Studio → Export → STL, units mm, resolution coarse or medium.
  • Fusion: right-click the body → Save as Mesh → STL (binary).
  • Sideways or backwards: change Axes, or turn it 90° with the 100 mm / 90° step. Tiny or huge: change Units. Then line up a known point (a pickup tab, the front bulkhead) by hovering over it and moving until its X Y Z match.

How to import it
  • SolidWorks: File → Open, pick the .igs or .step file, click Options… and turn on importing free point/curve entities as a 3D sketch. The points and lines arrive as a 3D sketch you can reference, dimension and mate to.
  • Fusion: Upload or Insert → Insert into current design. The lines come in as sketch curves.
  • Onshape: Import the .step file into a Part Studio; use the points and lines as references.
  • CSV: one row per named point, then one row per link (both ends), in the units and axes above.
  • STL: round tubes at your tube ODs, for clearance checks. STL has no units: choose the same units when you import it.

Part loads for FEA: one row per force: the axle, the load case, the part (upright, upper / lower wishbone, rocker), the point it acts at (ball joint, pivot, pushrod mount, tire contact patch…) and the force in N, in the same axes, origin and units as the geometry, so each point sits on the joint of a model built from the STEP export. In SolidWorks Simulation, fix the part at its pivots (or the ball joints, for the upright) and add each other row as a Remote Load at its X Y Z; in Onshape or Fusion, apply each force to the bore or face at that joint. Pick the worst cases (bump, pothole, kerb strike, the cornering cases) rather than all of them. The forces on each part balance, so a fixed support should carry close to nothing: a quick check that the loads went in right.

Corners are named FR, FL, RR, RL; the layers (IGES levels, STEP curve sets) are each corner at each pose. Blue = ride height, red = bump, green = droop, magenta / cyan = full rack either way. In a car file the rear corner is placed one wheelbase behind the front contact patch.
